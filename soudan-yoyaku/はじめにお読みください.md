# はじめにお読みください（相談予約システム）

このフォルダは、**LINE公式アカウントの中で完結する「無料相談の予約フォーム」一式**です。

## これは何？

LINE公式のリッチメニューを押すと、LINEの中で予約画面が開きます。お客様が日時を選んで「予約する」を押すと、裏側で次の3つが自動で動きます。

1. **Googleカレンダーに予定が入る**（Google Meet のURL付き）
2. **申し込み台帳（スプレッドシート）に1行追加される**（どの入口から来たかも記録）
3. **お客様のLINEに確認メッセージが届く**（前日にはリマインドも自動送信）

オンライン相談のURLは **Google Meet（自動発行）／Zoom（決まったURLを毎回案内）／なし** から選べます（設定1つで切り替え）。

エルメ（L Message）はそのまま使い続けられます。エルメの設定には一切触りません。

## フォルダの中身

| ファイル／フォルダ | 何か |
|---|---|
| `はじめにお読みください.md` | このファイル（人が読む） |
| `事前準備ガイド.md` | **アカウント側の設定手順**（LINE・Google・公開先）。ここが一番の山場 |
| `導入手順_ClaudeCodeに読ませる.md` | Claude Code に読ませて、設定ファイルの記入や公開を手伝ってもらう手順 |
| `gas/Code.gs` | 裏側の処理（Google Apps Script） |
| `gas/appsscript.json` | GASの設定ファイル |
| `frontend/index.html` | 予約画面 |
| `frontend/config.js` | 予約画面の設定（ここだけ書き換える） |
| `demo/` | 面談で見せた操作デモ（本番には使いません） |

## 使う前に必要なもの

- **LINE公式アカウント**（すでにエルメと接続済みでOK）
- **Googleアカウント**（カレンダーとスプレッドシートを使うもの）
- **Claude Code**（デスクトップアプリ）
- 予約画面を置く場所（**Vercel** の無料アカウントを推奨。GitHub Pages や Netlify でも可）

費用は **すべて無料枠で収まります**（LINEの通知は無料枠で月200通まで。1予約あたり2〜3通使います）。

## Claude Code に貼る導入プロンプト

Claude Code（デスクトップアプリ）などのAIエージェントのチャットに、**このまま貼り付ける**だけで始まります。Zipのダウンロードや解凍もAIがやります。

```
https://github.com/ryoya9595/my-ai-news の「soudan-yoyaku」フォルダにある「導入手順_ClaudeCodeに読ませる.md」を読んで、その手順どおりに進めてください。リポジトリはcloneして構いません。
```

Zipを先に受け取っている場合は、こちらでもOK：

```
soudan-yoyaku というフォルダの中の「導入手順_ClaudeCodeに読ませる.md」を探して読んで、その手順どおりに進めてください。フォルダはデスクトップかダウンロードフォルダにあります。
```

すると AI が **内容を説明 → 「進めてよろしいですか？」と確認 → 「はい」の後に作業**、という順で進めます。
**あなたがやるのは、ログイン・権限の許可・GASエディタでの関数実行・トークンの貼り付けだけ**です（下の表を参照）。それ以外の画面操作や設定はAIが進めます（ブラウザ操作の拡張「Claude in Chrome」が入っていると、より多くを任せられます）。

## 導入の流れ（全体像）

```
【1】事前準備ガイド.md に沿って、アカウント側の設定をする  ← 30〜60分・本人がやる
      LINE Developers でLIFFを作る／トークンを用意する／Googleの台帳を作る
        ↓
【2】Claude Code に「導入手順_ClaudeCodeに読ませる.md」を読ませる  ← 15分
      config.js の記入、GASの貼り付け案内、公開先へのアップロードを手伝ってくれる
        ↓
【3】自分のLINEから予約してテストする  ← 5分
      カレンダー・台帳・LINE通知の3つが動けば完成
        ↓
【4】エルメのリッチメニューにリンクを設定する
```

**【1】は Claude Code に画面を操作してもらえますが、次の4つだけは本人の操作が必要です**（2026-09-08 の導入テストで確認）。

| 本人がやること | どこで |
|---|---|
| Google / LINE / Vercel のログイン | 各サービスのログイン画面 |
| Google の権限の許可（「すべて選択」→続行） | clasp のログイン時と、GASの初回実行時 |
| **GASエディタで関数を実行する**（`applyDefaultConfig` / `selfCheck` / `installReminderTrigger`） | GASエディタ上部の関数プルダウン。**ここはAIが自動操作できません** |
| チャネルアクセストークンの貼り付け | GASのスクリプトプロパティ |

それ以外（台帳・カレンダーの作成、GASの配置とデプロイ、設定の記入、公開）は Claude Code が進めます。

## 入口ごとにリンクを分けると、経路が自動で記録されます

予約画面のリンクは、置く場所ごとに末尾を変えてください。

| 置く場所 | リンク | 台帳に記録される経路 |
|---|---|---|
| Instagram ストーリーズ | `https://liff.line.me/【LIFF ID】?src=story` | Instagram ストーリーズ |
| Instagram プロフィール | `https://liff.line.me/【LIFF ID】?src=profile` | Instagram プロフィール |
| LINE公式 リッチメニュー | `https://liff.line.me/【LIFF ID】?src=line` | LINE公式 リッチメニュー |

これだけで「どこから申し込みが来ているか」が台帳に自動で溜まります。

## お客様から見た開き方

| どこから押すか | 何が起きるか |
|---|---|
| **LINEのリッチメニュー／トーク内のリンク** | LINEの中でそのまま開く。**ログイン画面は出ません**。初回だけ「プロフィール情報の利用を許可」の画面が1回出る（許可を押すだけ。同時に友だち追加もされる） |
| **Instagram のストーリーズ／プロフィールのリンク** | スマホなら LINE アプリが起動して、その中で開く。LINE が入っていない人はブラウザで開き、LINEログインを求められる |
| **PCのブラウザで直接** | LINEログイン画面が出る。ログインすれば予約できる |

LINEログインを必須にしているのは、**確認メッセージを送るために、その人のLINE IDが必要**だからです。

## このキットがやらないこと

- お客様への**自動返信**（予約確認とリマインド以外は送りません）
- **キャンセル・日程変更の自動処理**（お客様からLINEで連絡をもらい、カレンダーを手で直す運用です）
- **予約ごとに個別のZoom URLを発行すること**（Zoomを使う場合は、いつもの固定URLを毎回案内する形になります。個別発行にはZoom API連携が必要です）

## 困ったら

| 症状 | 対処 |
|---|---|
| 予約画面が「設定が未完了です」と出る | `frontend/config.js` の `LIFF_ID` と `API_URL` が空。事前準備ガイドの控えを記入する |
| 【API_URL】を開くと「アクセスが拒否されました／ドライブ アクセス権が必要です」 | **スクリプトがまだ承認されていないだけ**です。ブラウザで【API_URL】を開き「Authorization needed」→ REVIEW PERMISSIONS →「詳細」→「（安全ではないページ）に移動」→「すべて選択」→続行 |
| 「空き枠を取得できませんでした」 | まず上の「承認」を試す。次にGASのデプロイ設定が「全員」になっているか確認。GASエディタで `selfCheck` を実行して原因を見る |
| 予約はできたがLINEに通知が来ない | チャネルアクセストークンが未設定か間違い。GASのスクリプトプロパティを確認 |
| 前日リマインドが来ない | `installReminderTrigger` を実行し忘れ。GASの「マイトリガー」に1件あるか確認 |
| Google Meet のURLが付かない | GASの「サービス」で Google Calendar API を追加しているか確認（付かなくても予約自体は動きます） |
| Zoomにしたのに Google Meet と案内される | スクリプトプロパティの `MEETING_TOOL` が `zoom` になっているか確認 |
| Zoomにしたら「Zoom（URLは前日にお送りします）」と出る | `ZOOM_URL` が空。Zoomの固定URLを入れる |
| 予定の時刻が9時間ずれる | GASの `appsscript.json` の `timeZone` が `Asia/Tokyo` になっているか確認 |
| 空き枠が1つも出ない | カレンダーが埋まっているか、営業時間の設定（`BUSINESS_START` / `BUSINESS_END`）を確認。**24時間以内の枠は出ない仕様**です（`MIN_LEAD_HOURS`） |

それでも解決しないときは、担当者に連絡してください。
