# 導入をサポートする人へ

このキットを、**あなたが誰かに設置してあげる／教えてあげる**ときに読む1枚です。
（設置する本人が読むのは `はじめにお読みください.md` → `事前準備ガイド.md` の順）

---

## 1. 30秒で説明する

> LINEの中で開く予約フォームです。お客様が日時を選ぶと、Googleカレンダーに予定が入って、
> スプレッドシートに申し込みが記録されて、お客様のLINEに確認メッセージが届きます。前日リマインドも自動。
> 今使っている配信ツール（エルメなど）の設定には一切触りません。費用はゼロです。

**ポイントは「今のLINE公式アカウントにそのまま足せる」こと。** 新しくLINE公式を作る必要はありません。

費用：全部無料枠に収まります。LINEの無料枠は月200通で、1予約あたり2〜3通使うので、**月60〜100件の予約までは無料**です。

## 2. 導入の全体像と時間

| 順番 | やること | 目安 |
|---|---|---|
| 1 | Googleの台帳（スプレッドシート）とカレンダーを用意 | 10分 |
| 2 | LINE Developers で予約画面用のチャネルとLIFFを作る | 20分 |
| 3 | 裏側の処理（GAS）を置いて公開する | 20分 |
| 4 | 予約画面をネットに公開する（Vercel） | 10分 |
| 5 | スマホで実際に予約してテスト | 10分 |

**初回は70分前後**を見てください（実測）。慣れれば40分ほど。
2〜4は Claude Code に `導入手順_ClaudeCodeに読ませる.md` を読ませると、ほとんど自動で進みます。

## 3. 事前に本人から集めておくもの

打ち合わせの前にこれを埋めておくと、当日は詰まりません。

| 聞くこと | なぜ必要か | つまずきポイント |
|---|---|---|
| **どのGoogleアカウントを使うか** | 台帳とカレンダーを作る場所 | 複数アカウントを持っている人は必ず1つに決める。**途中で別アカウントを選ぶと動きません** |
| **LINE公式アカウントを持っているか** | 予約フォームの土台 | 無ければ先に作ってもらう（無料） |
| **配信ツール（エルメ等）と繋いでいるか** | 触ってはいけない場所の確認 | 繋いでいる場合、**Webhook URL は絶対に触らない**。トークンの「再発行」も押さない |
| **LINE Developers にログインできるか** | 作業の前提 | 公式アカウントを管理しているのと同じLINEアカウントが必要 |
| **相談はMeetかZoomか** | 参加URLの出し方 | Zoomなら**固定URL**（`https://us06web.zoom.us/j/…`）を先に聞いておく |
| **相談枠の条件** | 空き枠の出し方 | 曜日／開始・終了時刻／1枠の長さ／昼休み／何日先まで／何時間前まで受けるか |
| **お客様に表示する名前とサービス名** | 確認メッセージの差出人など | 例「無料相談（60分）」 |
| **Vercelアカウント** | 予約画面の公開先 | GitHubアカウントがあると数クリックで作れる |

## 4. あなたが代行できること・できないこと

Claude Code を使えば大半は自動で進みますが、**次の5つは本人の手が必要**です（画面共有しながら「ここ押してください」と案内する形になります）。

| 本人がやる | どこで |
|---|---|
| Google / LINE / Vercel のログイン | 各サービスのログイン画面 |
| Googleの権限の許可（「すべて選択」→続行） | clasp のログイン時と、GASの初回実行時 |
| **GASエディタで関数を実行**（`applyDefaultConfig` / `selfCheck` / `installReminderTrigger`） | GASエディタ上部の関数プルダウン。**AIが自動操作できない場所です** |
| LINEのチャネルアクセストークンのコピー＆貼り付け | LINE Developers → GASのスクリプトプロパティ |
| すでにあるスクリプトプロパティの**値の書き換え** | 行の追加はAIができますが、既存の値の変更は通りません |

> トークンは、あなたも受け取らないでください。本人にコピーして本人に貼ってもらうのが安全です。

## 5. 詰まりどころ（実際に踏んだもの）

ここを知っているだけで、サポートの質がかなり変わります。

| # | 症状 | 本当の原因 | 対処 |
|---|---|---|---|
| 1 | 予約は動くが**Meetが付かない／お客様がアクセスできない** | `clasp create` がキットの `appsscript.json` を初期状態で**上書きする** | `clasp create` の直後、`push` の前に書き戻す |
| 2 | APIのURLを開くと**「ドライブ アクセス権が必要です」** | 権限設定のミスに見えるが、**スクリプトが未承認なだけ** | ブラウザでAPIのURLを開き「Authorization needed」から承認する |
| 3 | **前日リマインドだけ来ない** | `installReminderTrigger` の実行忘れ。**エラーが出ないので気づけない** | GASの「マイトリガー」に `sendReminders` が1件あるか必ず確認 |
| 4 | 予約はできるのに**友だち追加されない** | 「リンクされたLINE公式アカウント」が未設定。友だち追加オプションをOnにしても**自動では紐づかない** | チャネル基本設定から 編集→選択→更新 |
| 5 | **本人は開けるのに他の人は開けない** | LINEログインチャネルが「**開発中**」のまま | チャネル名の横のバッジから「公開」に切り替え |
| 6 | 一度動いたのに**更新したら壊れた** | `vercel --prod` が表示するURLは**そのデプロイ専用**で、次のデプロイで変わる | `vercel project ls` の Latest Production URL を使う |
| 7 | 予約もカレンダーも動くのに**LINE通知だけ来ない** | LIFFを別のプロバイダーに作っている。LINEのユーザーIDは**プロバイダー単位** | 配信ツールと繋がっているのと同じプロバイダー内に作る |

## 6. 終わったら必ず確認する3つ

1. **空き枠が出るか** … 予約画面を開いて、営業日に時間が並ぶ
2. **予約が4つ全部に届くか** … カレンダーに予定／台帳に1行／本人のLINEに確認メッセージ／管理者通知
3. **トリガーが登録されているか** … GASの「マイトリガー」に `sendReminders` が1件

3つ揃って初めて完了です。**2まで動いていても、3を忘れると前日リマインドだけ静かに動きません。**

テストで入れた予約は、カレンダーと台帳から消しておいてください。

---

## 7. 引き渡すときに伝えること

> - 予約のリンクは、置く場所ごとに末尾を変えると、どこから申し込みが来たか台帳に記録されます
>   （LINEのリッチメニュー `?src=line` ／ Instagramストーリーズ `?src=story` ／ プロフィール `?src=profile`）
> - 営業時間や枠の長さを変えたくなったら、GASの「スクリプト プロパティ」の数字を変えるだけです（作り直し不要）
> - キャンセルや日程変更は自動化していません。LINEで連絡をもらって、カレンダーを手で直す運用です

---

## 8. この仕組みが向いていない場合

- **同じ時間帯に複数人を受け付けたい** … 1枠1予約の設計です
- **予約ごとに別々のZoom URLを出したい** … 固定URLを毎回案内する方式です（個別発行はZoom API連携が必要）
- **決済まで一気にやりたい** … 決済機能はありません
