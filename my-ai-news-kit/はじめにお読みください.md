# はじめにお読みください（AIニュースリサーチ・スキル）

このフォルダは、**Claude Codeに「毎日のAIニュース調べ」をやってもらうためのスキル一式**です。

## これは何？

`/my-ai-news` と打つだけで、Claude Codeが

1. Chromeであなたの**Xアカウント**を開き
2. 「フォロー中」タイムラインを巡回して
3. その日のAI最新情報（新ツール・新モデル・アップデート）を箇条書きにまとめ
4. 拾った投稿には**その場でいいね**を付ける

というところまで自動でやってくれます。いいねしておけば、あとからスマホのXアプリの「いいね一覧」でゆっくり深掘りできます。

## 使う前に必要なもの

- **Claude Code**（デスクトップアプリ）※ Mac / Windows どちらでもOK
- **Claude in Chrome**（Chrome拡張）が有効になっていること ← **これが無いと動きません**
- **あなた自身のXアカウント**（自分で作ったもの。他人のアカウントは使いません）

> ⚠️ **Chrome拡張だけは先に入れておいてください。** このスキルはChromeを操作してXを読むので、拡張が無いと1ミリも動きません。導入時にClaude Codeが自動でチェックして、入っていなければ教えてくれます。

## 導入のしかた（3ステップ）

### 1. このフォルダをどこかに置く
Zipを解凍して出てきた `my-ai-news-kit` フォルダを、デスクトップなど分かる場所に置いてください。

### 2. Claude Codeを開いて、こう頼む

チャットに、このまま貼り付けてください：

```
my-ai-news-kit というフォルダの中の「導入手順_ClaudeCodeに読ませる.md」を探して読んで、その手順どおりに進めてください。フォルダはデスクトップかダウンロードフォルダにあります。
```

> 💡 **もっと確実なやり方**：`my-ai-news-kit` フォルダを Claude Code のチャット欄に**ドラッグ＆ドロップ**してから、
> 「このフォルダの `導入手順_ClaudeCodeに読ませる.md` を読んで、その手順どおりに進めてください」
> と送ると、場所を探す手間がなくなります。

すると Claude Code が

- **どんなスキルなのかを説明** →
- **「導入してよろしいですか？」と確認** →
- あなたが「はい」と答えてから導入

という流れで進めます。**勝手にインストールされることはありません。** 内容を聞いて「やっぱりやめる」と言えば、そこで止まります。

> 🔒 **今あるデータや、すでに入っている他のスキルが消えることはありません。**
> この導入でやるのは「`~/.claude/skills/my-ai-news/` というフォルダを新しく1つ作って、ファイルを1つ置く」だけです。削除も上書きもしません。

### 3. Claude Codeを再起動する

再起動したら、チャットで

```
/my-ai-news
```

と打てば使えます。「AIニュース調べて」でも動きます。

## 初回だけ、少し質問されます

初めて動かすと、スキルが次を聞いてきます。答えてあげてください。

1. **Xにログインできていますか？**（ログインは必ずご自身で。AIがID・パスワードを入力することはありません）
2. **AI情報アカウントをフォローしますか？** → おすすめのアカウント一覧を出してくれます。フォローしていいものを選んでください
3. **まとめた内容はどこに出しますか？**（Discordの部屋／チャットで報告／ファイル保存 など）

> 💡 フォローした直後はタイムラインがまだ育っていないので、1〜2日は情報が少なめです。数日でちゃんと流れてくるようになります。

## このスキルがやらないこと

- ポスト・リポスト・返信・DMは**一切しません**（いいねだけ）
- フォローの追加は、必ずあなたに確認してから
- Xのログイン情報をAIが入力することはありません

## 困ったら

| 症状 | 対処 |
|---|---|
| `/my-ai-news` が出てこない | Claude Codeを再起動する |
| ブラウザが動かない | Chrome拡張「Claude in Chrome」が有効か確認する |
| 情報が全然集まらない | フォロー数が足りません。「おすすめアカウントもう一回出して」と頼んでください |
| Windowsでコマンドがエラーになる | Claude Codeに「Windowsなので、PowerShell用のコマンドで進めて」と伝えてください（手順書にWindows用も書いてあります） |

それでもダメなら、りょうやさんに聞いてください。
