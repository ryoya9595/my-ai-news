# 【Claude Codeへの指示】LINE内 相談予約フォームの導入

このファイルを読んだAIへ。以下の手順で進めてください。

> ⚠️ **重要①：確認を取る前に、勝手に変更しないこと。**
> ステップ1で担当者から明確な「はい」をもらうまで、ファイルの編集・コマンド実行・外部サービスへの公開は一切しないでください。
>
> ⚠️ **重要②：既存のデータ・設定を絶対に消さないこと。**
> - `rm` / `rm -rf` / `mv` は使わない
> - 担当者のPCにある他のフォルダ・ファイルには触らない
> - このキットのフォルダの中だけで作業する
>
> ⚠️ **重要③：ログイン・認証・トークンの発行は、必ず担当者本人がやる。**
> - LINE Developers・Google・Vercel のログインをAIが代行しない
> - チャネルアクセストークンなどの秘密情報を、チャット上に貼り出さない・ファイルにコピーしない（担当者が自分で入力する）
> - **LINE公式アカウントの Webhook URL と「再発行」ボタンには絶対に触れないよう、担当者にも念押しする**（エルメが止まります）

> 💻 Mac / Windows 共通。コマンドはOSごとに書き分けてあります。

## ステップ0：まず全体像を説明する（作業はまだしない）

担当者に次を伝えてください。

> このキットで作るのは「LINEの中で完結する、無料相談の予約フォーム」です。
>
> **できること**：お客様がLINEのリッチメニューから予約画面を開き、日時を選んで予約すると、Googleカレンダーに予定が入り、スプレッドシートの台帳に記録され、お客様のLINEに確認メッセージが届きます。前日リマインドも自動です。
>
> **エルメへの影響**：ありません。別のチャネルに登録する仕組みなので、エルメの設定には触りません。
>
> **作業の分担**：
> - 担当者がやること：LINE Developers・Google・Vercel でのアカウント設定（`事前準備ガイド.md` の内容。ログインが必要なので本人が操作します）
> - 私（AI）がやること：設定ファイルの記入、公開先へのアップロード、動作確認の案内
>
> **所要時間**：担当者の設定に30〜60分、その後の作業に15分ほど。

続けて、`事前準備ガイド.md` が終わっているか聞いてください：

> 「`事前準備ガイド.md` の STEP 1〜3 は終わっていますか？（LIFF ID と、GASのウェブアプリURL が手元にある状態）」

- **終わっていない** → 「先に `事前準備ガイド.md` を進めてください。画面を見ながら案内することもできます」と伝え、担当者が希望すればガイドの内容を1ステップずつ読み上げて案内する。**この場合もAIは画面操作を代行しない**
- **終わっている** → ステップ1へ

## ステップ1：作業してよいか確認を取る

> 「これから `frontend/config.js` に LIFF ID と API URL を記入し、予約画面を Vercel に公開します。進めてよろしいですか？（はい／いいえ）」

「はい」以外なら進めない。質問には答えてよい。

## ステップ2：config.js を記入する

担当者に次を聞いて、`frontend/config.js` を編集してください（**トークンは聞かない**。config.js にトークンは入りません）。

1. LIFF ID（例：`1234567890-AbCdEfGh`）→ `LIFF_ID`
2. GASのウェブアプリURL（`/exec` で終わる）→ `API_URL`
3. 画面に出す名前 → `HOST_NAME`
4. ご相談内容の選択肢を変えたいか → `TOPICS`
5. テーマ色を変えたいか → `ACCENT`（省略可）

編集後、内容を表示して確認してもらう。

## ステップ3：予約画面を公開する（Vercel）

### 3-1. Vercel CLI があるか確認

**Mac / Linux**
```
which vercel || echo "not installed"
```
**Windows（PowerShell）**
```
Get-Command vercel -ErrorAction SilentlyContinue
```

無ければインストール（Node.js が必要。無い場合は https://nodejs.org からLTSを入れてもらう）：
```
npm install -g vercel
```

### 3-2. ログイン（担当者本人が操作）
```
vercel login
```
→ ブラウザが開くので、担当者にログインしてもらう。**AIはメールアドレスやパスワードを入力しない。**

### 3-3. 公開

`frontend` フォルダに移動して：

**Mac / Linux**
```
cd "<このキットのパス>/frontend"
vercel --prod --yes
```
**Windows（PowerShell）**
```
Set-Location "<このキットのパス>\frontend"
vercel --prod --yes
```

- 初回は「Set up and deploy?」などと聞かれる → すべて Enter（デフォルト）でOK。プロジェクト名は `soudan-yoyaku` など分かりやすいものに
- 最後に表示される `https://xxxx.vercel.app` を担当者に伝え、**【FRONT_URL】として控えてもらう**

> 💡 Vercel を使わない場合（GitHub Pages / Netlify 等）は、`frontend` の2ファイルをそのまま置けば動きます。サーバー側の処理は不要です。

### 3-4. 動作確認
公開URLをブラウザで開いてもらう。LINEの外なので「LINEログイン」を求められるのが正常。
（`config.js` の `REQUIRE_LINE_LOGIN` を一時的に `false` にすると、ログインなしで画面だけ確認できます。確認後は必ず `true` に戻して再デプロイ）

## ステップ4：LIFFのエンドポイントを差し替えてもらう（担当者が操作）

> 「LINE Developers → LINEログインチャネル → LIFF → 作ったLIFF を開いて、『エンドポイントURL』を `【FRONT_URL】` に変更して保存してください（末尾の `/` は不要）」

## ステップ5：テストを案内する

担当者に次を順に案内し、結果を聞いてください。

1. 自分のスマホのLINEで `https://liff.line.me/【LIFF_ID】?src=line` を開く
2. 空き時間が表示されるか
3. 1件予約してみる
4. 確認：Googleカレンダーに予定 → スプレッドシートに1行 → LINEに確認メッセージ
5. **エルメのテスト配信が今までどおり届くか**
6. テスト予約をカレンダーから削除

### うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 「設定が未完了です」 | `config.js` の `LIFF_ID` / `API_URL` が空。再デプロイも忘れずに |
| 「空き枠を取得できませんでした」 | GASのデプロイで「アクセスできるユーザー：全員」になっているか。GASエディタで `selfCheck` を実行してもらい、ログを教えてもらう |
| LINE通知が来ない | GASのスクリプトプロパティ `LINE_CHANNEL_ACCESS_TOKEN` の有無。GASの「実行数」画面でエラーを確認 |
| 予約画面が真っ白 | `config.js` の記法ミス（カンマ抜け等）。ブラウザのコンソールのエラーを見る |
| Meet のURLが付かない | GASの「サービス」に Google Calendar API が追加されているか。付かなくても予約は動く |
| `vercel: command not found` | Node.js 未導入。https://nodejs.org からLTSを入れて、ターミナルを開き直す |

## 更新したいとき（担当者に頼まれたら）

- **予約画面の文言・色・選択肢**：`frontend/config.js` を編集 → `vercel --prod --yes` で再公開
- **営業時間・枠の長さ・リマインド時刻**：GASのスクリプトプロパティを変更（コードの変更・再デプロイは不要）
- **裏側の処理（Code.gs）**：GASエディタに貼り直し → 「デプロイを管理」→ 新バージョンでデプロイ（URLは変わらない）

## アンインストール

担当者から**明確に「消して」と言われたときだけ**：
1. Vercel のプロジェクトを削除（Vercel の画面から、担当者が操作）
2. GAS のトリガー（`sendReminders`）を削除、必要ならプロジェクトごと削除（GASエディタから、担当者が操作）
3. LINE Developers の LIFF を削除（担当者が操作）

**Messaging APIチャネル・エルメの設定・スプレッドシート・カレンダーは消さない。**
