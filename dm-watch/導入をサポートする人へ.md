# 導入をサポートする人へ

このキットを、**あなたが誰かに設置してあげる／教えてあげる**ときに読む1枚です。
（設置する本人が読むのは `はじめにお読みください.md` → `事前準備ガイド.md` の順）

---

## 1. 30秒で説明する

> 1日4回（10時・14時・17時・19時）、Claudeのクラウドが Instagram の新着DMを見にいって、
> 対応が必要なものだけ返信案つきで LINE に通知します。PCを閉じていても動きます。
> Instagram 側への返信や操作は一切しません。**読むだけ**です。

**「DMを見逃さないための見張り」であって、「自動で返信するツールではない」** ——ここを最初に伝えると誤解が出ません。

---

## 2. いちばん最初に伝えること（同意が要る）

Instagram を**プロアカウント**（クリエイター推奨）に切り替える必要があります。切り替えると：

- **非公開アカウントにできなくなります**
- **保留中のフォローリクエストが自動で承認されます**
- 商用利用が許可されていない音源が使えなくなります

**これは元に戻すのに手間がかかる変更です。** 先に説明して、納得してもらってから進めてください。
非公開で運用している人・フォローリクエストを選別している人には、この時点で「向いていない」と伝えるほうが親切です。

---

## 3. 導入の全体像と時間

| 順番 | やること | 目安 | 誰が |
|---|---|---|---|
| 1 | Instagram をプロアカウントに切り替え | 5分 | 本人（スマホ） |
| 2 | Meta for Developers でアプリを作り、トークンを発行 | 30〜50分 | 画面はAI、開発者登録・パスワード入力・Instagramログインは本人 |
| 3 | 通知用の LINE公式アカウントを作る | 15分 | 画面はAI、ログインは本人 |
| 4 | Claude のクラウド環境にトークンを登録 | 10分 | 貼り付けは本人 |
| 5 | リポジトリに置いてルーティンを作る | 15分 | ほぼAI |

**合計55〜100分。** いちばん時間がかかるのは 2 の Meta です。

> 🔴 **Meta でいちばん詰まるのは「開発者登録」です**（2026-09-08 実測）。
> 初めて developers.facebook.com を使う人は、アプリ作成の前に4ステップの開発者登録が挟まります。
> そのうち **「Verify account（電話番号のSMS認証）」が、Facebookアカウントに電話番号を登録していないと
> 「セキュリティ上の理由から、電話番号はまずアカウントセンターで追加する必要があります」と出て進めません。**
> 事前に本人へ「Facebookアカウントに電話番号を登録しておいてください」と伝えておくと、ここで止まりません
> （https://accountscenter.facebook.com/personal_info/contact_points から追加）。

> ⚠️ **Meta の管理画面は名称と配置がよく変わります。** ガイドと表示が違っても、同じ意味の項目を探して進めてください。
> 迷ったら画面のスクリーンショットを Claude に見せて「どれを押せばいい？」と聞くのが早いです。

## 4. 事前に本人から集めておくもの

| 聞くこと | なぜ必要か |
|---|---|
| Instagram のアカウント（@名） | 監視対象。プロアカウントに切り替えられるか要確認 |
| **プロアカウント化して問題ないか** | 上の「2.」の同意。ここが最大の関門 |
| Facebook アカウントを持っているか | Meta for Developers のログインに使う（無ければ作成）。**Instagram と連携させる必要はない** |
| **Facebookアカウントに電話番号を登録済みか** | 未登録だと開発者登録の「Verify account」で止まる（上の🔴） |
| Facebook のパスワードを本人がすぐ出せるか | アプリ作成の最後にパスワード再入力を求められる |
| Claude のプラン（Pro / Max / Team） | Pro/Max は API credentials、Team は環境変数と手順が分かれる |
| 通知を受け取る人（本人だけか、複数か） | 複数に送ると1通が人数分カウントされる |
| GitHub アカウント | キットを置く非公開リポジトリ用 |

## 5. あなたが代行できないこと

| 本人がやる | どこで |
|---|---|
| Instagram のプロアカウント切り替え | スマホのInstagramアプリ |
| Instagram / Facebook / LINE / GitHub のログイン | 各サービス |
| **Facebook のパスワード再入力** | Meta のアプリ作成の最後 |
| **Instagramテスター招待の「承認する」** | instagram.com → 設定 → アプリとウェブサイト → テスターへのご招待（利用規約への同意を伴う） |
| Instagram のアクセス許可 | Meta のトークン発行時 |
| トークンのコピー＆貼り付け（Instagram・LINE） | Claude 環境の API credentials |
| 通知用LINEアカウントの**友だち追加** | スマホのLINEでQRを読む |

> **トークンはあなたも受け取らないでください。** 本人がコピーして本人が貼るのが安全です。
> `scripts/refresh_token.py` は新しいトークンを画面に表示するので、**AIに実行させないでください**。

## 6. 詰まりどころ

| 症状 | 原因 | 対処 |
|---|---|---|
| **「開発者の役割が不十分です」**（Instagramログイン後） | その Instagram アカウントがアプリの **Instagramテスター**になっていない | 事前準備ガイド STEP 2-4 を実施（役割→その他→Instagramテスター→追加→Instagram側で承認） |
| **Meta の開発者登録の「Verify account」が進まない** | Facebookアカウントに電話番号が未登録 | アカウントセンター → 連絡先情報 で電話番号を追加してから戻る |
| **通知が来ない（エラーも出ない）** | 新着DMが無いだけ。**正常です** | 別アカウントから自分にDMを送って「今すぐ実行」で確認 |
| `"stage": "auth"` で失敗 | 環境の API credentials に `graph.instagram.com` が無い／トークンが違う | 登録内容を確認 |
| LINE送信が `401` | API credentials に `api.line.me` が無い | 同上 |
| LINE送信が `400`（`to` 関連） | `LINE_TO_USER_ID` が違う、または**友だち追加していない** | QRから友だち追加 |
| **約60日後に突然止まる** | Instagram のトークンの有効期限切れ | 下の「7.」参照 |
| きっかりの時刻に来ない | 仕様。サーバー負荷分散で数分ずれる | 説明しておく |

### ルーティンを作るときの注意（見落としやすい）

- 画面上の「**指示**」がプロンプト欄です（「プロンプト」という項目名ではありません）
- **環境の選択欄は独立していません。**「指示」欄の下にある雲アイコン＋環境名のボタンです
- **cron の入力欄は「カスタム」を選ばないと出てきません**。cron は **UTC** です
- 🔴 **コネクターが既定で6個ほどONになっています**（Gmail・Google Drive などを含む）。
  このシステムには不要で、付けたままだと**確認なしで書き込みできる権限**が付きます。**必ず全部「×」で外してください**

## 7. 引き渡すときに必ず伝えること

> **Instagram のトークンは約60日で切れます。** 切れると「⚠️ Instagram DMチェックが失敗しました」というLINEが届きます。
> 発行から50日後くらいにカレンダーへリマインドを入れておいてください。更新方法は事前準備ガイドの最後にあります。

これを伝えていないと、2か月後に「いつの間にか止まっていた」となります。**ここが一番のクレーム源です。**

その他：
- 通知の時刻・判定基準・文面は、ルーティンの「指示」を書き換えれば変えられます
- 止めたいときは、ルーティンを一時停止するだけでOKです

---

## 8. この仕組みが向いていない場合

- **非公開アカウントのままにしたい** … プロアカウント化が必須なので使えません。
  Meta 側でも「トークンは、公開Instagramアカウント用にのみ生成できます」と明示されています
- **DMに自動返信してほしい** … 返信案を出すだけで、送信はしません
- **リアルタイムで知りたい** … 1日4回のチェックです（時刻は変更できます）
