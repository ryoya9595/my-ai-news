# はじめにお読みください（DMウォッチシステム）

このフォルダは、**決まった時刻に Instagram のDMを確認して、対応が必要なものだけ LINE に知らせる仕組み**一式です。

## これは何？

毎日 **10時・14時・17時・19時** に、Claude が自動で立ち上がって

1. Instagram の新着DMを取りに行く
2. 1件ずつ読んで「要対応／確認／対応不要」に分ける
3. 要対応のものには返信案を付けて、**LINEに1通にまとめて送る**

新着がなければ何も送りません（静かなままです）。

Instagram のアプリを開かなくても取りこぼしがなくなり、返信案があるのでコピペで即返信できます。

## どこで動く？

**Claude のクラウド上**で動きます。PCもスマホも閉じていて大丈夫です。
自分で作った Claude Code の「ルーティン」が、指定した時刻に自分のアカウントで動く、という仕組みです。

## フォルダの中身

| ファイル | 何か |
|---|---|
| `はじめにお読みください.md` | このファイル |
| `事前準備ガイド.md` | **アカウント側の設定手順**（Instagram・Meta・LINE・Claude環境）。ここが山場 |
| `導入手順_ClaudeCodeに読ませる.md` | Claude Code に読ませて、リポジトリへの配置とルーティン作成を手伝ってもらう手順 |
| `導入をサポートする人へ.md` | **誰かに設置してあげる人が読む1枚**（事前に集めるもの・詰まりどころ・引き渡し時に伝えること） |
| `routine-prompt.md` | ルーティンに貼るプロンプト（Claude が毎回やること） |
| `scripts/fetch_dms.py` | Instagram からDMを取ってくるスクリプト |
| `scripts/send_line.py` | LINE に送るスクリプト |
| `state/` | 通知済みのDM IDを記録する場所（自動で作られます） |

## 使う前に必要なもの

- **Instagram のプロアカウント**（ビジネス or クリエイター。個人アカウントでは使えません。切り替えは無料）
- **Facebook アカウント**（Meta for Developers に入るために必要。Instagram と連携させる必要はありません。
  **電話番号を登録済みのもの**にしてください。未登録だと開発者登録の途中で止まります）
- **Meta for Developers のアプリ**（自分のアカウント名義で作る。無料）
- **LINE公式アカウント**（通知を受け取る用。既存のものでOK）
- **Claude の Pro または Max プラン**（クラウドのルーティンと、トークンを安全に保管する機能を使うため）
- 通知を受け取る人の **LINE userId**

費用は **無料枠で収まります**（LINEの通知は月200通まで無料。1日最大4通 × 30日 = 120通。新着がない時間帯は送らないので実際はもっと少ないです）。

## Claude Code に貼る導入プロンプト

Claude Code（デスクトップアプリ）などのAIエージェントのチャットに、**このまま貼り付ける**だけで始まります。Zipのダウンロードや解凍もAIがやります。

```
https://github.com/ryoya9595/my-ai-news の「dm-watch」フォルダにある「導入手順_ClaudeCodeに読ませる.md」を読んで、その手順どおりに進めてください。リポジトリはcloneして構いません。
```

Zipを先に受け取っている場合は、こちらでもOK：

```
dm-watch というフォルダの中の「導入手順_ClaudeCodeに読ませる.md」を探して読んで、その手順どおりに進めてください。フォルダはデスクトップかダウンロードフォルダにあります。
```

すると AI が **内容を説明 → 「進めてよろしいですか？」と確認 → 「はい」の後に作業**、という順で進めます。
**あなたがやるのは、ログインと、トークンの貼り付けだけ**です。画面の操作や設定はAIが進めます（ブラウザ操作の拡張「Claude in Chrome」が入っていると、より多くを任せられます）。

> ⚠️ Instagram のプロアカウント切り替えだけは**スマホの操作**なので、AIの案内に沿ってご自身でお願いします。

## 導入の流れ（全体像）

```
【1】事前準備ガイド.md に沿って、アカウント側の設定をする  ← 45〜90分・本人がやる
      Instagramをプロアカに／Metaアプリを作る／トークンを取る／Claude環境に登録
        ↓
【2】Claude Code に「導入手順_ClaudeCodeに読ませる.md」を読ませる  ← 15分
      リポジトリにキットを置く／接続テスト／ルーティン作成を案内
        ↓
【3】ルーティンを1回手動で動かして、LINEに届くのを確認  ← 5分
```

## ⚠️ 事前に知っておくこと

- **Instagram をプロアカウントに切り替えると、非公開アカウントにできなくなります**（保留中のフォローリクエストは自動承認されます）。また、商用利用不可の音源が使えなくなります。「クリエイター」を選ぶと音源の制限はゆるめです。
- Meta のアクセストークンには**有効期限（約60日）**があります。期限が近づいたら更新が必要です（手順は事前準備ガイドの最後）。
- DMの内容は、判定と要約のために **Claude に読まれます**。お客様に案内する場合は、プライバシーポリシー等への記載をおすすめします。

## この仕組みがやらないこと

- Instagram への**返信・既読・フォローなどの操作は一切しません**（読むだけ）
- DMの全文をLINEに転記しません（要約だけ）
- 新着がないときは通知しません

## 通知の重複について

LINEへの送信が失敗した回のDMは、**次の実行でもう一度通知されます**（取りこぼすよりよいという設計）。
同じDMが2回届くことがまれにありますが、正常な動作です。

## 困ったら

| 症状 | 対処 |
|---|---|
| LINEに「⚠️ Instagram DMチェックが失敗しました」と届く | 本文の error を見る。`HTTP 190` や `OAuthException` ならトークン期限切れ → 事前準備ガイドの「トークンの更新」 |
| 何も届かない | 新着がないだけの可能性が高い。ルーティンの実行履歴（claude.ai/code）で「count: 0」と出ていれば正常 |
| **Instagram に未読DMがあるのに `count: 0` になる** | 下の「新着DMが取れないとき」を参照 |
| ルーティンが失敗している | 実行履歴のログを見る。環境の API credentials に `graph.instagram.com` と `api.line.me` が両方あるか確認 |
| 同じDMが2回届く | リポジトリへの push 権限がなく、通知済みの記録が残っていない。ルーティン設定でブランチへの push を許可する |

## 新着DMが取れないとき（2026-09-09 の導入テストで遭遇）

Instagram アプリの受信箱には未読DMがあるのに、API（`me/conversations?platform=instagram`）が
`data: []` を返し、`count: 0` になることがあります。**エラーは出ません**（トークンは有効、レート制限でもない）。

確認した事実：

- トークンは有効（`me` は正常に応答する）
- 「メッセージリクエスト」フォルダではなく、**通常の受信箱**に届いていても起きる
- 取得の時間窓を7日に広げても 0 件のまま

**まず疑うべきもの（最有力）**：

- 🔴 **Instagram アプリの「メッセージへのアクセスを許可する」がオフ**
  → 事前準備ガイドの **STEP 1-2** を実施してください。プロアカウント化だけでは足りず、
  このトグルが別にあります（初期状態オフ・**スマホアプリからしか変更できません**）。
  オフのままだと、他が全部正しくてもエラーなしで会話0件になります。

検証済みで**否定された**もの：

- 「フォロー外のDMがメッセージリクエストに入っている」→ ✗（通常の受信箱に届いていても起きた）
- 「Instagramテスター承認より前のDMは取れない」→ ✗（承認**後**に送ったDMでも0件だった）

それでもダメなときに疑うもの：

- アプリが「**未公開（開発モード）**」であることによる制限
  → 公開するには Meta の「公開」ページで**プライバシーポリシーURL**の設定が必要です

いずれにせよ、**新規に届くDMを拾えれば運用上は問題ありません**（このキットは新着だけを通知するものです）。

それでも解決しないときは、担当者に連絡してください。
