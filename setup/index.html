Setup Guide

無料相談を、
自動で回す仕組み

Instagram で見つけてもらい、LINE で予約を受ける。 その流れを自動化する仕組みです。必要なものだけ入れられます。

導入はすべて無料枠に収まります。サーバーの契約は要りません。

この仕組みは Claude Code（デスクトップアプリ）で導入します。
各セクションの黒いボックスを Claude Code に貼り付けると、あとは会話しながら進みます。 あなたにお願いするのは ログイン・権限の許可・トークンの貼り付け だけです。

1相談予約システム

LINE のリッチメニューから開く予約画面です。お客様が日時を選ぶと、Google カレンダーに予定が入り、 申し込み台帳に1行記録され、お客様の LINE に確認メッセージが届きます。前日リマインドも自動です。

いま使っている LINE 公式アカウント（エルメ等と接続済みでも可）にそのまま足せます。配信ツールの設定には触りません。

必要なもの

  • LINE 公式アカウント（無料）と、それを管理している LINE アカウント
  • Google アカウント（カレンダーと台帳を置く。複数持っている場合は1つに決めておく）
  • Vercel の無料アカウント（GitHub アカウントがあると数クリック）
  • オンライン相談に使うもの … Google Meet（自動発行）か、Zoom の決まった URL
所要 70分ほど 費用 0円 月60〜100予約まで無料
Claude Code に貼る次のリポジトリをこのブランチで clone して、soudan-yoyaku フォルダの「導入手順_ClaudeCodeに読ませる.md」を読み、その手順どおりに導入を進めてください。 git clone -b claude/line-notification-mechanism-ciml75 https://github.com/ryoya9595/my-ai-news.git ~/Desktop/soudan-yoyaku-src 私はログインと、画面に出たトークンの貼り付けだけ担当します。それ以外の画面操作と設定はあなたが進めてください。

2DM ウォッチシステム

1日4回（10時・14時・17時・19時）、Instagram の新着 DM を確認して、 対応が必要なものだけ返信案つきで LINE に通知します。PC を閉じていても動きます。

Instagram 側への返信・フォロー・いいねは一切しません。読むだけです。

先に確認してください。この仕組みは Instagram をプロアカウントに切り替える必要があります。切り替えると——
  • 非公開アカウントにできなくなります
  • 保留中のフォローリクエストが自動で承認されます
  • 商用利用が許可されていない音源が使えなくなります
元に戻すのは手間がかかります。問題ないことを確かめてから始めてください。

必要なもの

  • Instagram アカウント（プロアカウントに切り替えられること）
  • Facebook アカウント（Meta for Developers のログインに使います。無ければ作成）
  • 通知を受け取る LINE（通知専用の公式アカウントを新しく作るのがおすすめ）
  • Claude の Pro / Max / Team いずれかのプラン
所要 45〜90分 費用 0円 約60日ごとにトークン更新
Claude Code に貼る次のリポジトリをこのブランチで clone して、dm-watch フォルダの「導入手順_ClaudeCodeに読ませる.md」を読み、その手順どおりに導入を進めてください。 git clone -b claude/line-notification-mechanism-ciml75 https://github.com/ryoya9595/my-ai-news.git ~/Desktop/dm-watch-src Instagram をプロアカウントに切り替える影響を先に説明してください。私はログインと、画面に出たトークンの貼り付けだけ担当します。

導入する前に決めておくこと

ここが埋まっていると、当日ほとんど詰まりません。

決めることなぜ必要か
どの Google アカウントを使うか台帳とカレンダーを置く場所。途中で別のアカウントを選ぶと動きません
LINE 公式アカウントを配信ツールと繋いでいるか繋いでいる場合、触ってはいけない設定があります（Webhook URL とトークンの「再発行」）
相談は Meet か Zoom かZoom なら決まった URL を先に用意しておきます
相談を受ける曜日・時間・1枠の長さ空き枠の出しかたに使います（昼休み、何日先まで、何時間前まで も）
お客様に表示する名前とサービス名確認メッセージの差出人などに出ます

うまくいかないとき

症状まず見るところ
予約画面が「設定が未完了です」と出るconfig.js の設定が空。Claude Code に「config.js を確認して」と伝える
自分は開けるのに、他の人が予約画面を開けないLINE ログインチャネルが「開発中」のまま。「公開」に切り替える
予約はできるのに LINE 通知だけ来ないチャネルアクセストークンの設定。友だち追加をしているかも確認
前日リマインドだけ来ないinstallReminderTrigger の実行忘れ。エラーが出ないので気づきにくい箇所です
DM の通知が来ない新着 DM が無いだけのことがあります。別のアカウントから自分に DM を送って確認
DM チェックが突然止まったInstagram のトークンが約60日で切れます。更新してください

導入手順の詳細は、clone したフォルダの中の「はじめにお読みください.md」「事前準備ガイド.md」に入っています。
誰かに設置してあげる立場の方は「導入をサポートする人へ.md」もあわせてお読みください。
